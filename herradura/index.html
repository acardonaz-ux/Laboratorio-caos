Lectura matemática

La herradura permite estudiar una dinámica complicada mediante una geometría sencilla.

Nota: la construcción representa un modelo local de la herradura clásica, rotado 90° respecto a la orientación habitual de estiramiento horizontal. No es todavía la aplicación global en todo el plano ni el automorfismo cociente estudiado en la tesis.

Controles: ←/→ para avanzar en la construcción o las iteraciones; Espacio para reproducir/pausar; F para pantalla completa. Aplicación local sin bibliotecas externas ni conexión a internet. En «Iterar la herradura» se usa una extensión geométrica fuera de Q para visualizar toda la imagen.
